# Atlas website

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Static HTML, CSS and JavaScript, hosted on GitHub Pages from a dedicated public directory. No application backend or analytics.

## Users and purpose
Visitors learn briefly about Atlas, browse its source and download the Windows launcher. The first screen places the GitHub and download actions together in the centre. Russian and English are required.

## Product truth
Atlas is SFrostStar's independent Rust Minecraft client and Electron launcher based on Horizon. The published Windows x64 portable release is currently Atlas 1.0.0. Source commits can be newer than the downloadable release. Local native mod ports are not Java/Fabric binary compatibility. Do not claim benchmark improvements or completed Microsoft sign-in.

## Confirmed brand and constraints
Keep the Atlas name, existing orange logo and dark night landscape. This task does not redesign the launcher or game. Use a short, approximately five-second non-blocking introduction with restrained movement. Respect reduced-motion preferences. No subagents.

## Evidence
Repository README, current GitHub release assets, launcher artwork and Atlas engine night background. Preserve Horizon attribution and third-party licences. No player screenshots, worlds, profiles or local builds are published.
