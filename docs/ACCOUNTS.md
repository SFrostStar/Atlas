# Аккаунты Atlas

Локальный профиль работает без Microsoft-входа: одиночная игра, LAN и серверы, допускающие локальные имена. Для online-mode серверов нужен Microsoft-аккаунт с Minecraft: Java Edition.

## Однократная настройка приложения

Это делает владелец Atlas, а не каждый игрок. Пользователь готового лаунчера только нажимает вход и подтверждает его на сайте Microsoft.

1. Зарегистрируй приложение **Atlas** в [Microsoft Entra](https://entra.microsoft.com/), поддерживающее личные Microsoft-аккаунты.
2. В Authentication включи **Allow public client flows**. Для входа по коду redirect URI и Client Secret не нужны.
3. Укажи Application (client) ID в `package.json` → `atlasMicrosoft.clientId`. Для локальной разработки можно вместо этого задать `ATLAS_MSA_CLIENT_ID`.
4. Если Minecraft возвращает отказ регистрации приложения, запроси доступ к Minecraft API через [App ID review](https://aka.ms/mce-reviewappid). Подготовленный интерфейс входа не заменяет одобрение внешнего сервиса.

Client ID — публичный идентификатор, не секрет. Нельзя подставлять ID чужого лаунчера. Пароль и токены присылать не нужно.

## Как работает вход

Atlas показывает код и открывает официальный сайт Microsoft. Пароль вводится только в браузере на сайте Microsoft. Лаунчер проходит OAuth device flow → Xbox Live → XSTS → Minecraft, проверяет право на игру и профиль. Отмена входа прекращает опрос; истёкший код можно получить заново.

Refresh-токен и Minecraft-токен шифруются Electron `safeStorage` средствами текущего пользователя Windows. В `data/accounts.json` находятся имена, UUID и зашифрованные данные; содержимое токенов не передаётся интерфейсу и не записывается в журнал. Если защищённое хранилище недоступно, сохранения открытым текстом нет.

При запуске выбранный Microsoft-профиль проверяется заново, а истекающий токен обновляется. Недоступность сети не превращает Microsoft-профиль в локальный автоматически: локальный профиль выбирается явно.

Игра получает одноразовый файл сессии из приватного каталога с Windows ACL. Она читает его и сразу удаляет. При неудачном запуске лаунчер удаляет файл; оставшийся файл дополнительно удаляется через две минуты и отказывается приниматься игрой после истечения этого срока. После аварийного завершения лаунчера старые файлы удаляются при следующем запуске. Выход из аккаунта удаляет его сохранённые токены из списка Atlas; уже запущенная игра продолжает свою текущую сессию.

Протокол входа: [Microsoft OAuth device authorization grant](https://learn.microsoft.com/en-us/entra/identity-platform/v2-oauth2-device-code).
