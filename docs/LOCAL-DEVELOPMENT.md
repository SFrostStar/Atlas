# Atlas Launcher

Локальный лаунчер, собранный клиент и исходники Atlas 26.3.

## Открыть

Двойной щелчок по **Atlas Launcher.lnk** в этой папке. Готовое приложение лежит в `dist/Atlas Launcher-win32-x64/Atlas Launcher.exe`.

Для разработки интерфейса: `npm install`, затем `npm start`. Основные файлы — `index.html`, `styles.css`, `renderer.js`. Код запуска и работа с папками — `main.cjs`, `lib/launcher-store.cjs`. Проверки: `npm test`. Пересборка готового лаунчера после правок: `npm run package`.

UI-проверка: запусти dev-окно с `npm start -- --remote-debugging-port=9227`, затем `node tests/ui-smoke.cjs`. Для изолированной проверки новых настроек и переводов: `node tests/preferences-ui.cjs` и `node tests/localization-ui.cjs`. Они используют тестовый профиль в `work/` и не меняют рабочие сборки.

## Что работает

- Создание и выбор Instances с сохранением после перезапуска.
- Независимые папки миров, ресурспаков, настроек и логов: `data/instances/<id>`.
- Запуск своего клиента Atlas с отдельной папкой выбранной сборки.
- Открытие корня проекта, файлов сборки, исходников и журналов.
- Язык интерфейса: русский и английский; светлая и тёмная темы, пять акцентов.
- Персонализация главной: пейзаж, закат или минимальный фон, текст и анимации.
- Отдельный лимит памяти каждой сборки, применяемый при следующем запуске. Это лимит выделенной памяти нативного процесса Windows, не Java-параметр. По умолчанию ограничения нет.
- Локальные профили и подготовленный Microsoft-вход. Для Microsoft нужен собственный Client ID Atlas; пока он не настроен, локальные профили работают. Инструкция — `docs/ACCOUNTS.md`.
- Собственный `runtime/atlas-client.exe` и локальное управление через `runtime/atlas-ctl.exe`.
- ПКМ по «Игра запущена»: остановка, перезапуск, дополнительное окно и выбор клиента. Остановка сохраняет игру, перезапуск ждёт завершения выбранного клиента.
- ПКМ по сборке: открытие папки и удаление в корзину с подтверждением. Открытая или последняя сборка защищена от удаления.
- Discord Rich Presence: общий Atlas, оранжевая A, текст и версия установленной сборки. Настройка — в лаунчере; регистрация пользователям не нужна.

Дополнительные окна используют отдельные сохранения в `data/sessions/<id>/home/saves`; туда копируются настройки и ресурспаки выбранной сборки. Существующие миры не копируются и не открываются одновременно двумя клиентами.

Подготовленные ресурсы Minecraft находятся локально в `runtime/.local/atlas-client/26.3`. При первом запуске новой версии прежние файлы настроек сборок переименовываются в `atlas-*` с резервной копией в `work/legacy-data-backup`. Миры и содержимое настроек сохраняются. При конфликте существующих файлов сохраняются оба варианта.

## Изменять саму игру

Исходники в `engine/atlas`. Подпись главного меню — **Atlas 26.3**, заголовок окна — **Atlas**. Названия меню, справка и сообщения клиента также используют Atlas. Полная инструкция: `docs/EDITING-ATLAS.md`.

Клиент собран с аудио, контроллерами и WASM-модами; лаунчер автоматически использует `runtime/atlas-client.exe`. Для пересборки после правок закрой игру и запусти **Build Atlas.cmd**. Локальные Rust и LLVM-MinGW уже лежат в `tools/`, установка Visual Studio не требуется. Системный PATH не менялся.

Для каждого запущенного окна лаунчер создаёт собственный сокет в `data/control`. Путь для команды `runtime/atlas-ctl.exe --socket "ПУТЬ" state` можно скопировать в игровых настройках Agent Control. `runtime/atlas-ctl.exe --help` показывает команды. Настройка No AI сохраняет приоритет.

Иконка лаунчера — прозрачная оранжевая A (`assets/atlas-launcher.ico`), у игры — отдельный блок травы из локальных ресурсов Minecraft. Перегенерация: `scripts/Generate-Icons.ps1`. Игровая иконка остаётся локальной и не предназначена для публикации вместе с исходниками.

Версия лаунчера задаётся в `package.json`: `0.1.0` отображается как `v0.1`; следующую `v0.11` можно выпустить с версией `0.11.0`. Общий Discord Application ID и ключ изображения находятся в `atlasDiscord` того же файла. Секретов Discord в лаунчере нет. Подробнее — `docs/DISCORD.md`.

Изменение CSS/JS лаунчера не требует Rust. Настройки самой игры доступны в Atlas Settings внутри Minecraft.
