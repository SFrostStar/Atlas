# Discord Rich Presence

Atlas подключается к настольному Discord по локальному IPC. Для пользователя достаточно включить Discord Rich Presence; создавать своё приложение или вводить Application ID не нужно. Bot token, client secret и чтение данных Discord не требуются.

В профиле должны отображаться:

```text
Atlas
The Fastest minecarft launcher
v0.1
```

Название **Atlas** Discord берёт из зарегистрированного приложения, а не из произвольного текста клиента. Публичный Application ID `1565017139516285079` и ключ изображения `atlas` входят в настройки сборки лаунчера. Версия карточки берётся из версии Atlas: сейчас `v0.1`. Старое приложение Horizon для этой активности не используется.

## Настройка владельцем приложения

Регистрация Discord-приложения и загрузка логотипа выполняются владельцем Atlas один раз в [Discord Developer Portal](https://discord.com/developers/applications). Пользователи лаунчера используют это же приложение и готовое изображение. Для большого логотипа карточки нужен **Rich Presence → Art Assets** с ключом **atlas**; аватар приложения — отдельное изображение.

Если владелец меняет приложение или ключ asset, он обновляет общие настройки сборки Atlas. Изображения из папки компьютера напрямую в карточку Discord не передаются. После загрузки asset возможна задержка кеша Discord.

## Проверка

Статус «Подключено» появляется только после `READY` и подтверждённой команды `SET_ACTIVITY`; одно открытие канала не считается успехом. Если Discord отклоняет ID или активность, лаунчер показывает ошибку и повторяет попытку позже. При выключении Presence отправляется пустая активность.

Проверка 28 октября 2026: локальный Discord подтвердил Application ID `1565017139516285079`, название **Atlas**, указанный текст, `v0.1` и логотип `atlas` — поле `largeImage` разрешилось в asset `1565020217917055176`.

Важная настройка Discord: показ активности должен быть разрешён самим пользователем в Discord. Atlas не меняет настройки приватности Discord автоматически.

## Техническая основа

- [Официальный RPC over IPC](https://docs.discord.com/developers/topics/rpc#rpc-over-ipc): именованные каналы Windows `\\?\pipe\discord-ipc-0` … `9`, handshake с Application ID, подтверждение `READY`.
- [SET_ACTIVITY](https://docs.discord.com/developers/topics/rpc#set_activity): `details`, `state`, `assets.large_image`, PID приложения.
- [Rich Presence](https://docs.discord.com/developers/platform/rich-presence): публичная карточка активности и загруженные изображения.

Модуль `lib/discord-rpc.cjs` работает асинхронно и не задерживает показ окна или секундную заставку. Повторные подключения выполняются с паузой, кадры ограничены размером 1 MiB, ping получает pong. Тесты используют отдельный локальный сервер и не отправляют фиктивную активность в настоящий Discord.
